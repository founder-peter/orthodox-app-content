# Orthodox app: downloadable texts

The texts that the Orthodox app (a free, non-profit app) downloads when a reader wants them. The app reads
`catalogue.json`, then downloads each pack from `packs/<id>.json` and keeps it on the phone for offline use.

These files are made by `tools/make_packs.py` in the app's own repository. Please don't edit them by hand.
