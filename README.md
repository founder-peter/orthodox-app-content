# Orthodox App: downloadable texts

Texts that the Orthodox app (a free, non-profit app) downloads to people's phones when they choose them, so they can be read offline.

This repository holds only public-domain or freely licensed texts:

| Text | Source | Licence |
| --- | --- | --- |
| Divine Liturgy of St John Chrysostom, Greek and English | J. N. W. B. Robertson, *The Divine Liturgies of Our Fathers Among the Saints* (London, 1894) | Public domain |
| Saints of each day | English Wikipedia, "[Month] [day] (Eastern Orthodox liturgics)" pages | Creative Commons Attribution-ShareAlike 4.0 |

The texts are added here by the app's maintainers. Full source details are kept with each file.
